Entry for the make.fun competition "One-Liner Marathon". `main.py` writes a single one-line comedy joke — 115 characters, inside the 280-character cap — to `/output/entry.txt`.

> My AI writes my emails, runs my calendar, and answers my messages — I've officially been promoted to its assistant.

The joke is built for the judge's brief: it works as a joke in a single line, with the setup listing three real jobs the AI took over and the turn riding on one word — "promoted" — which sounds like a rise and lands as a demotion. Every word earns its place, the voice is a specific first-person deadpan rather than a generic gag, and the inversion still reads funny the second time: the assistant's competence is exactly the problem.

Run it with `python3 main.py`; it needs no network and writes only `/output/entry.txt`.
